What the automation is proving

  • The diff tooling can produce concrete visual evidence instead of hand-wavy “it feels off.”
  • /ui-heuristic-score can turn that evidence into a structured ship decision.
  • A bounded polish pass can improve the score without pretending the UI is magically perfect.
  • The next step is clear: either do one more polish pass or escalate to ab_test_visuals.

Bounded subagent follow-up

The demo stops short of an uncontrolled self-improvement loop. Instead it hands off to the new bounded worker/reviewer chain:

pi -e ./pi-packages/pi-subagents
# then in Pi:
/ui-autopolish tighten the demo dashboard layout using \
  artifacts/ui-automation-demo/regression-diff.json and \
  artifacts/ui-automation-demo/current-score.md as context
