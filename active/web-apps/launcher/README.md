# Megarepo Launcher

🚀 **The starting point for all web-based work in the megarepo.**

Dashboard to start, stop, and browse all web apps. Public at [shsw.dev](https://shsw.dev).

## Documentation

Canonical documentation lives at:
- [Web docs](https://calvinloveland.github.io/megarepo/projects/active/web-apps/launcher/)
- Local source: [`docs/index.md`](docs/index.md)

## New Web Work

When building new web-based features or apps for the megarepo:
1. The launcher is the starting point — register new apps in `apps.yaml`
2. The documentation site (MkDocs) is the canonical reference — add project docs in `docs/`
3. Update `projects.yaml` when adding significant new projects
