How it works

The decoder is fixed — only the latent vector is stored per image.

1

Train

A VAE learns to encode images into a 1,000-dimensional latent space and decode them back.

→
2

Encode

Any image is fed through the encoder. Out comes a compact 1,000-float latent vector.

→
3

Quantize

Each float is rounded to 8 bits using per-vector adaptive bounds — 79% less error than fixed ranges.

→
4

Store

~1 KB per image: 28 bytes header + 1,000 bytes of quantized latent. That's it.
