# Recursive Thermofluid Sandbox

A browser-based physics sandbox where **the wheel is the only active machine element**.

Players build pumps, compressors, turbines, refrigerators, steam engines, and power loops by arranging:

- wheels
- walls
- fluids
- heat
- materials
- recursive 3×3 cells

There are **no hard-coded machine classes**.

## What this prototype includes

- A recursive 3×3 grid world with drill-down into nested cells
- Per-cell thermofluid state:
  - gas mass
  - liquid mass
  - temperature
  - pressure
  - velocity
  - material type
- Automatic phase change for water/steam and refrigerant-like fluids
- Powered wheels that consume exactly **1 watt each**
- Free wheels that can spin from flow and feed power back into the shared network
- Activity-driven hierarchical expansion and collapse
- Presets for:
  - pump loop
  - compressor
  - turbine
  - refrigerator loop
  - steam engine

## Test the physics model

```bash
npm test
```

The test suite checks prototype invariants including:

- hotter gas produces higher pressure
- reduced free volume raises pressure
- boiling and condensation move mass between phases with latent-heat effects
- pressure gradients and gravity move fluids in the expected direction
- walls block fluid transport but still conduct heat
- powered wheels request exactly 1 watt each
- free wheels can generate power from flow
- total fluid mass stays approximately conserved over a tick
- recursive regions expand and collapse based on activity
- subdivision preserves parent mass
- wheel direction changes local tangential flow sign
- copper conducts more heat than insulation
- the server serves `sim-core.mjs` with a JavaScript MIME type so mobile browsers can load the module graph correctly

## Notes

This is an emergence-focused sandbox prototype, not a CFD solver. The simulation is intentionally approximate, but it now uses the corrected **3×3 recursive cell design** from the updated brief. The app is structured around the rules from that design:

- one active component
- passive physics elsewhere
- hierarchical world detail
- mass / momentum / heat interactions
- power generated by fluid-driven wheels
