Ammo Comparison Table

Every cartridge in Wikipedia’s handgun and rifle table, plus shotgun loads and current-production rounds. Each row carries the cartridge’s origin, age, designer, bullet dimensions, and a ballistic profile; energy, power factor, effective range, and trajectory are computed from bullet weight and muzzle velocity, not copied from a chart. The Case action finds the fewest numeric columns that can still put a chosen load first.

The case for

The panel solves for the fewest columns that can still put this load first, then splits the weight as evenly as possible between them — “it is the cheapest” is treated as a better argument than “it is cheapest and softest and lightest”. Each of those columns is checked to be load-bearing: drop one and the load loses first place. When no weighting wins, the closest case found is shown instead, and the note says so when that weighting is a single column. Newer design, heavier bullet, velocity, energy, and range score higher; recoil and cost score lower. Power factor is shown but not weighted: inside a class it is the same measurement as recoil. Pistol comparisons also score compact case length, because shorter cartridges fit smaller frames; that criterion is not used for rifle or shotgun comparisons. Unpriced loads count as the most expensive when cost carries weight. Clear the case to use the filters and column sorting again.

Profile

How to read this. Curated rows are typical commercial loads from everyday barrel lengths (pistol ≈ 4″, rifle ≈ 22–24″, shotgun ≈ 28″), so a hotter or slower load of the same cartridge will read differently. The extended reference rows come from Wikipedia’s cartridge table, which lists independent maxima for velocity and energy; their bullet weight is derived from the published momentum so each row describes one coherent load. Energy is gr × fps² / 450437 foot-pounds; power factor is gr × fps / 1000. Energy bars use a logarithmic scale so rimfire and anti-materiel rounds can share one column. Shotgun rows use the whole payload, so their power factor is not comparable to a single projectile.

Cost per round is shown only for cartridges with a current commercial load and is a rough retail estimate for relative comparison only. Obsolete, surplus, and collector cartridges have no stable price, so their cost is left blank rather than invented. “Introduced” is the year the cartridge was introduced; the line under each name gives its nation, bullet diameter, and case length. “Designer” is the person or organisation named in the cartridge’s Wikipedia infobox; some cartridges were developed by a company or service rather than one inventor, and a dash means no source names one. Bullet cells show the selected unit plus, where known, the range of weights normally sold for that cartridge. Click a row for platforms, reference metadata, notes, and the trajectory table. The silhouette beside each load is drawn from its case length, bullet diameter, and bullet weight; common cartridges use published SAAMI or C.I.P. case dimensions, the rest use inferred case bodies, and sizes use a compressed scale so small rounds stay legible. True dimensions are printed in the row. Cartridge coverage and reference values adapted from Wikipedia’s Table of handgun and rifle cartridges (CC BY-SA).

Make the case. The Case button finds a non-negative weighting of the numeric columns (with compact case length added for pistols) that puts the selected load first, and it looks for the one that needs the fewest columns — “cheapest alone” beats “cheapest and softest and lightest”. Weight is then split as evenly as possible inside that set, and the table shows the comparison set sorted by the weighted percentile score. When no weighting can win against all loads, the case tries centerfire or rimfire and then the load’s own category; the “Compare against” menu exposes each set. If no weighting wins anywhere, the feature reports the closest case found instead of pretending the load is first, and says when that weighting is really a single column. A load that only ties for first keeps its place in the ranking: it is never floated above the loads it ties with. Newer design and heavier bullet are treated as “more is better”; recoil and cost are “less is better.” A blank cost is treated as the most expensive value so unpriced surplus does not win by default.

Range and trajectory are estimates. “Eff. range” is the farthest 25-yard step at which the load still carries a usable energy floor for its role — 75 ft·lb for rimfire, 300 for pistols, 250 for varmints, and 1,000 for other rifles — with a 75%-of-muzzle-energy floor for weak legacy rounds and practical caps for pistol, rimfire, varmint, and anti-materiel loads. Shot shells are pattern-limited (40 yd); slugs use 100 yd, or 150 for sabots. The trajectory table uses a published G1 ballistic coefficient where the data has one and a sectional-density estimate otherwise, with a 50-yard zero for pistols and rimfire and a 100-yard zero for rifles and shotguns. The drag model is deliberately simple: compare loads with it, don’t use it as a dope card.
